---
title: 'Close Job'
api: 'POST /v1/recruiter/close'
description: 'Close an active job posting on LinkedIn'
---

Close an active job posting on LinkedIn, removing it from the available positions list and stopping new applications.

<Note>
  This endpoint costs **1 credit** per job closing operation. Ignore this if you're on per-seat pricing: usage is unlimited.
</Note>

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

### Body Parameters

<ParamField body="login_token" type="string" required>
  LinkedIn authentication cookie obtained from the login/verify process
</ParamField>

<ParamField body="job_id" type="string" required>
  LinkedIn job posting ID to close
</ParamField>

<ParamField body="country" type="string" default="FR">
  Country code for proxy selection. Available: US, CA, MX, CR, BR, AR, CL, CO, FR, UK, DE, NL, ES, IT, PT, BE, CH, AT, IE, SE, DK, FI, LT, LV, EE, PL, CZ, SK, HU, RO, UA, SI, HR, RS, AL, GR, CY, TR, IL, AE, EG, ZA, IN, PK, BD, JP, SG, MY, ID, TH, PH, AU
</ParamField>

### Response

<ResponseField name="status" type="string">
  Request status (success/error)
</ResponseField>

<ResponseField name="message" type="string">
  Status message
</ResponseField>

<ResponseField name="details" type="string">
  Additional error details (in case of error)
</ResponseField>

<ResponseExample>
```json Success Response
{
  "status": "success",
  "data": {
            "job_id": job_id,
            "message": "Job posting successfully closed",
            "closed_at": current_timestamp
          }
}
```
</ResponseExample>
