## Overview

Two actions on LinkedIn events, both on `POST /v2/network`:

- `get_event`: when the event starts and ends, its state, organizer, venue, speakers, and the account's own status towards it.
- `invite_to_event`: invite 1st-degree connections to it.

<Note>This endpoint consumes **1 credit** per request. Ignore this if you're on per-seat pricing: usage is unlimited.</Note>

<ParamField header="x-api-key" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField body="account_id" type="string" required>
  The unique identifier of the account to use.
</ParamField>

## Get event

`action: "get_event"`

Returns the details of a LinkedIn event from its URL, URN or id: when it starts and ends (as UTC instants and as wall-clock times in the event's own time zone), whether it is upcoming, ongoing or past, who organizes it, where it happens or streams, and the account's own status towards it (invited, attending, host).

### Request

<ParamField body="action" type="string" required>
  Must be `"get_event"`.
</ParamField>

<ParamField body="params" type="object" required>
  <Expandable title="params properties">
    <ParamField body="event_url" type="string" required>
      The event: URL (`https://www.linkedin.com/events/launch7315105458780465155/`), `urn:li:fsd_professionalEvent:…` or the numeric event id. `event_id` is accepted as an alias.
    </ParamField>
  </Expandable>
</ParamField>

## Invite to event

`action: "invite_to_event"`

Invites one or more members to a LinkedIn event, the same way the **Invite** button on the event page does. LinkedIn only lets you invite your **1st-degree connections**. On a public event any member can invite their connections; on a private or organizer-only event, the organizer and co-hosts. The event is read first: a deleted or cancelled event is refused before any invitation is sent.

Up to 50 profiles per call. Each profile is resolved first; a profile LinkedIn cannot find is reported in `results` and does not block the others.

### Request

<ParamField body="action" type="string" required>
  Must be `"invite_to_event"`.
</ParamField>

<ParamField body="params" type="object" required>
  <Expandable title="params properties">
    <ParamField body="event_url" type="string" required>
      The event: URL (`https://www.linkedin.com/events/7315105458780465155/`), `urn:li:fsd_professionalEvent:…` or the numeric event id. `event_id` is accepted as an alias.
    </ParamField>
    <ParamField body="profiles" type="string[]" required>
      The people to invite (max 50): profile URLs, public slugs, member ids (`ACoAA…`) or `urn:li:fsd_profile:…`. A single `profile_url` string is accepted for one person.
    </ParamField>
  </Expandable>
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  Indicates whether the request was successful.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="data properties">
    <ResponseField name="event_id" type="string">
      Numeric id of the event.
    </ResponseField>
    <ResponseField name="event_urn" type="string">
      `urn:li:fsd_professionalEvent:…` of the event.
    </ResponseField>
    <ResponseField name="event_name" type="string | null">
      Title of the event.
    </ResponseField>
    <ResponseField name="invited_count" type="integer">
      How many of the profiles were invited.
    </ResponseField>
    <ResponseField name="results" type="object[]">
      One entry per profile given, in order.
      <Expandable title="result properties">
        <ResponseField name="profile" type="string">The profile as you passed it.</ResponseField>
        <ResponseField name="profile_id" type="string">Resolved member id (`ACoAA…`), when found.</ResponseField>
        <ResponseField name="profile_urn" type="string">Resolved `urn:li:fsd_profile:…`, when found.</ResponseField>
        <ResponseField name="status" type="string">`invited`, or `error`.</ResponseField>
        <ResponseField name="invitation_id" type="string">Id of the created invitation, as a string (19 digits). Inviting someone already invited returns the existing invitation.</ResponseField>
        <ResponseField name="invitation_urn" type="string">`urn:li:fsd_invitation:…` of the invitation.</ResponseField>
        <ResponseField name="message" type="string">Why this person was not invited (only on `error`).</ResponseField>
        <ResponseField name="linkedin_code" type="string">LinkedIn's own refusal code for this person, when it gives one (e.g. already invited, already attending).</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="object">
  <Expandable title="metadata properties">
    <ResponseField name="action" type="string">The action that was performed (`"invite_to_event"`).</ResponseField>
    <ResponseField name="account_id" type="string">The account ID used for the request.</ResponseField>
    <ResponseField name="credits_consumed" type="integer">Number of credits consumed (1).</ResponseField>
    <ResponseField name="timestamp" type="string">ISO 8601 timestamp of the response.</ResponseField>
  </Expandable>
</ResponseField>
