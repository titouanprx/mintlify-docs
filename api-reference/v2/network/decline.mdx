---
title: 'Decline Invitation'
api: 'POST /v2/network'
description: 'Decline a pending connection invitation.'
---

## Overview

Declines (ignores) a pending connection invitation using the invitation's `shared_secret` and `entity_urn`. These values can be obtained from the [List Invitations](/api-reference/v2/network/list-invitations) endpoint. The sender is not notified, as on LinkedIn.

Same request and response as [Accept Invitation](/api-reference/v2/network/accept) — only `action` changes.

<Note>This endpoint consumes **1 credit** per request.</Note>

## Request

<ParamField header="x-api-key" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField body="account_id" type="string" required>
  The unique identifier of the account to use.
</ParamField>

<ParamField body="action" type="string" required>
  Must be `"decline"`.
</ParamField>

<ParamField body="params" type="object" required>
  <Expandable title="params properties">
    <ParamField body="shared_secret" type="string" required>
      The shared secret associated with the invitation. Obtained from the invitation data.
    </ParamField>
    <ParamField body="entity_urn" type="string" required>
      The entity URN of the invitation to decline.
    </ParamField>
  </Expandable>
</ParamField>

</ResponseField>
