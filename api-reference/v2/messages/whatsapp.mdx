## Overview

- Same endpoints and response formats as LinkedIn: [`/v2/login`](/api-reference/v2/accounts/login), [`/v2/checkpoint`](/api-reference/v2/accounts/checkpoint), [`/v2/messages`](/api-reference/v2/messages/send), [webhooks](/api-reference/v2/webhooks/introduction)
- Phone numbers in international format: `+33612345678`
- Connecting is free. Each `/v2/messages` action costs **1 credit**

## Connect a number

1. `POST /v2/login` → returns a QR code
2. On the phone: WhatsApp › Settings › Linked devices › Link a device, scan the QR
3. Poll `POST /v2/checkpoint` with the `account_id` every few seconds → current QR while pending, `connected` once scanned

<ParamField body="platform" type="string" required>`whatsapp`</ParamField>
<ParamField body="phone_number" type="string">The number to link. Required with `pairing_code`.</ParamField>
<ParamField body="params.pairing_code" type="boolean" default={false}>Get an 8-character code to type on the phone instead of a QR.</ParamField>

```json Request
{ "platform": "whatsapp", "phone_number": "+33612345678" }
```

- The QR refreshes every ~20 s and expires after 3 min. Then call `/v2/checkpoint` with `resend: true` for a new one
- `country` defaults to the number's country

## Send

`action: "send"` with `phone_number` (or `conversation_id`) and `message_text`. Attachments with `media_link(s)` / `media_file(s)`, as on LinkedIn.

```json Request
{ "account_id": "your-whatsapp-account-id", "action": "send", "params": { "phone_number": "+33612345678", "message_text": "Hi!" } }
```

A number without WhatsApp returns `CHANNEL_ERROR` (422).

## Check numbers

`action: "check_numbers"` tells which numbers are on WhatsApp. Up to 50 per call. Nothing is sent to them.

```json Request
{ "account_id": "your-whatsapp-account-id", "action": "check_numbers", "params": { "phone_numbers": ["+33612345678", "+33600000000"] } }
```

## Inbox

- `list_inbox`, `get_conversation`, `search`: same params as LinkedIn. `get_conversation` also accepts `phone_number`
- `mark_as_read` / `mark_as_unread` with `conversation_id`
- Attachments: [`GET /v2/messages/attachment`](/api-reference/v2/messages/download-attachment) with `account_id` + `message_id`
