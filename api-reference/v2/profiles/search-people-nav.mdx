## Overview

Run a **Sales Nav lead search** and get back richly-detailed leads. This uses the account's Sales Nav seat — see [Connect Account](/api-reference/v2/accounts/login) to activate it.

There are two ways to define the search — pick whichever fits:

1. **Friendly filters** — pass human-readable values (e.g. `seniority_level: ["Director", "CXO"]`) and the API resolves them to the underlying ids for you.
2. **Copied Sales Nav URL** — build the search visually in Sales Nav, copy the page URL, and pass it as `sales_nav_url`. Every filter is replicated verbatim, including ones with no friendly mapping (persona, lead lists, exclusions, buyer intent, …).

<Note>This endpoint consumes **1 credit per 10 results** returned. Requires a Sales Nav seat on the account.</Note>

<Info>
Within a single filter, multiple values are combined with **OR** (e.g. `seniority_level: ["VP", "CXO"]` = VP **or** CXO). Different filters are combined with **AND**.
</Info>

### Paging

`offset: 0, count: 25` returns leads 0–24, `offset: 25` the next 25. The response echoes `offset` back, so the next page is `offset + total_results`.

<Warning>
Sales Nav only lets a single search be browsed up to **2500 results**, whatever `total_available_results` reports. An `offset` of 2500 or more returns `INVALID_PARAMS` (0 credits) — narrow the filters to reach deeper leads.
</Warning>

<Tip>
Every list filter also accepts raw ids directly, so you can mix friendly names and ids. Unknown values are ignored rather than causing an error.
</Tip>

## Examples

### Friendly filters

```json
{
  "account_id": "your-account-id",
  "action": "search_people_nav",
  "params": {
    "keyword": "marketing",
    "seniority_level": ["Vice President", "CXO"],
    "function": ["Marketing", "Sales"],
    "company_type": ["Public Company"],
    "company_size": "51-1000",
    "industry": ["Software Development"],
    "company_headquarters": ["North America", "EMEA"],
    "years_in_current_position": ["3 to 5 years"],
    "count": 25
  }
}
```

### Copied Sales Nav URL

```json
{
  "account_id": "your-account-id",
  "action": "search_people_nav",
  "params": {
    "sales_nav_url": "https://www.linkedin.com/sales/search/people?query=(filters:List(...))",
    "offset": 0,
    "count": 25
  }
}
```
