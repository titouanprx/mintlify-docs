---
title: 'Update Profile'
api: 'POST /v2/profiles'
description: 'Edit the connected account’s own profile in one call: intro, about, experience, education and skills.'
---

<Note>This endpoint consumes **1 credit** per request. Ignore this if you're on per-seat pricing: usage is unlimited.</Note>

- Send only what you want to change.
- `experience` / `education` entries: no `id` = add, `id` = edit, `id` + `delete: true` = delete. The ids come from [Get Me](/api-reference/v2/profiles/get-me).
- The network is never notified unless an entry has `notify_network: true`.

## Request

<ParamField header="x-api-key" type="string" required>
  Your API key.
</ParamField>

<ParamField body="account_id" type="string" required>
  The account whose profile is edited.
</ParamField>

<ParamField body="action" type="string" required>
  Must be `"update"`.
</ParamField>

<ParamField body="params" type="object" required>
  <Expandable title="params properties">
    <ParamField body="first_name" type="string" />
    <ParamField body="last_name" type="string" />
    <ParamField body="headline" type="string" />
    <ParamField body="about" type="string">Send `""` to clear it.</ParamField>
    <ParamField body="website" type="string" />
    <ParamField body="experience" type="array">
      <Expandable title="entry properties">
        <ParamField body="id" type="string">To edit or delete an entry.</ParamField>
        <ParamField body="delete" type="boolean">`true` to delete the entry.</ParamField>
        <ParamField body="title" type="string">Required to add.</ParamField>
        <ParamField body="company" type="string" />
        <ParamField body="company_id" type="string">
          From [Typeahead](/api-reference/v2/profiles/typeahead) `type: "company"`. Without it the company shows as plain text.
        </ParamField>
        <ParamField body="description" type="string" />
        <ParamField body="location" type="string" />
        <ParamField body="location_id" type="string">From Typeahead `type: "location"`.</ParamField>
        <ParamField body="start_date" type="string">`"YYYY-MM"` or `"YYYY"`.</ParamField>
        <ParamField body="end_date" type="string">`"YYYY-MM"` or `"YYYY"`.</ParamField>
        <ParamField body="is_current" type="boolean" />
        <ParamField body="notify_network" type="boolean" default="false" />
      </Expandable>
    </ParamField>
    <ParamField body="education" type="array">
      <Expandable title="entry properties">
        <ParamField body="id" type="string">To edit or delete an entry.</ParamField>
        <ParamField body="delete" type="boolean">`true` to delete the entry.</ParamField>
        <ParamField body="school" type="string">Required to add.</ParamField>
        <ParamField body="school_id" type="string">From Typeahead `type: "school"`.</ParamField>
        <ParamField body="degree" type="string" />
        <ParamField body="field_of_study" type="string" />
        <ParamField body="start_date" type="string">`"YYYY-MM"` or `"YYYY"`.</ParamField>
        <ParamField body="end_date" type="string">`"YYYY-MM"` or `"YYYY"`.</ParamField>
        <ParamField body="grade" type="string" />
        <ParamField body="activities" type="string" />
        <ParamField body="description" type="string" />
        <ParamField body="notify_network" type="boolean" default="false" />
      </Expandable>
    </ParamField>
    <ParamField body="skills" type="object">
      `{"add": ["Python"], "remove": ["Java"]}`, by skill name.
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```json Request
{
  "account_id": "your-account-id",
  "action": "update",
  "params": {
    "headline": "Head of Growth @ Acme",
    "about": "I help B2B teams grow.",
    "experience": [
      { "title": "Head of Growth", "company": "Acme", "start_date": "2024-03", "is_current": true },
      { "id": "2543928369", "description": "Led the platform team." },
      { "id": "3046062887", "delete": true }
    ],
    "education": [
      { "school": "HEC Paris", "degree": "MSc", "start_date": "2018", "end_date": "2020" }
    ],
    "skills": { "add": ["Growth Marketing"], "remove": ["Java"] }
  }
}
```
</RequestExample>

<ResponseExample>
```json 200
{
  "success": true,
  "data": {
    "updated": true,
    "fields": ["headline", "about", "experience[0]", "experience[1]", "experience[2]", "education[0]", "skills.add Growth Marketing", "skills.remove"]
  }
}
```

```json 400
{
  "success": false,
  "error": {
    "code": "INVALID_PARAMS",
    "message": "experience[0]: title is required to add an entry"
  }
}
```
</ResponseExample>

<Note>Changes are applied in order. If one is refused, the error names it and lists the changes already applied.</Note>
