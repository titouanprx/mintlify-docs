---
title: 'Update Profile'
api: 'POST /v2/profiles'
description: 'Edit the connected account’s own profile: intro, about, experience, education and skills.'
---

<Note>Each request consumes **1 credit**. Ignore this if you're on per-seat pricing: usage is unlimited.</Note>

## Actions

| Action | Use |
|---|---|
| `update` | Name, headline, about, website |
| `list_profile_items` | Ids of the experience, education or skills entries |
| `get_profile_item` | Current fields of one entry |
| `add_profile_item` | Add an entry |
| `update_profile_item` | Edit an entry (experience, education) |
| `delete_profile_item` | Delete an entry |

- The network is never notified unless you send `notify_network: true`.
- A skill can't be edited: delete it and add the new one.
- `add_profile_item` doesn't return the new id: `list_profile_items` gives it.

<RequestExample>
```json update
{
  "account_id": "your-account-id",
  "action": "update",
  "params": { "headline": "Founder @ Acme", "about": "We build..." }
}
```

```json add_profile_item
{
  "account_id": "your-account-id",
  "action": "add_profile_item",
  "params": {

    "company_id": "1035",

  }
}
```

```json update_profile_item
}
```
