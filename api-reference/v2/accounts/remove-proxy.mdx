---
title: 'Remove Custom Proxy'
api: 'DELETE /v2/accounts/{account_id}/proxy'
description: 'Back to a LinkupAPI-managed proxy'
---

<Note>
  This endpoint is **free** — it does not consume any credits.
</Note>

### Path Parameters

<ParamField path="account_id" type="string" required>
  The account. Must belong to your API key.
</ParamField>

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

<ResponseExample>
```json Success Response
{
  "success": true,
  "data": {
    "account_id": "69c127c37cae0494dd827286",
    "proxy": { "mode": "managed" },
    "removed": true
  },
  "metadata": {
    "action": "remove_account_proxy",
    "credits_consumed": 0,
    "timestamp": "2026-09-09T16:16:42.702403"
  }
}
```
</ResponseExample>

### Notes
- `removed: false` when the account had no custom proxy
