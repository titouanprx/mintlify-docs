---
title: 'Delete Account'
api: 'DELETE /v2/accounts/{account_id}'
description: 'Disconnect an account and delete everything attached to it'
---

Disconnects a channel account and removes it, along with everything attached to it.

<Note>
  This endpoint is **free** — it does not consume any credits.
</Note>

<Warning>
Permanent. Reconnecting later means a full [Connect Account](/api-reference/v2/accounts/login) and a new `account_id`. To pause temporarily, stop the webhooks instead.
</Warning>

### Path Parameters

<ParamField path="account_id" type="string" required>
  The account to delete. Must belong to your API key.
</ParamField>

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

### What gets deleted

- the real-time monitor is stopped, which **halts its billing**
- every webhook on the account
- the cached connections snapshot
- stored webhook events
- the account itself

### Response

<ResponseField name="success" type="boolean">
  Whether the deletion succeeded
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="Properties">
    <ResponseField name="account_id" type="string">
      The account that was deleted
    </ResponseField>
    <ResponseField name="deleted" type="boolean">
      Always `true` on success
    </ResponseField>
    <ResponseField name="webhooks_deleted" type="integer">
      Number of webhooks removed
    </ResponseField>
    <ResponseField name="connections_deleted" type="integer">
      Number of cached connection snapshots removed
    </ResponseField>
    <ResponseField name="events_deleted" type="integer">
      Number of stored webhook events removed
    </ResponseField>
  </Expandable>
</ResponseField>

### Notes
- The Sales Nav seat goes with the account. The licence is untouched — reconnect with `sales_nav: true` to restore the seat
- An account owned by another API key returns `404`, same as an unknown one
- Safe to repeat: a second delete returns `404`
- Does not log the user out of LinkedIn
