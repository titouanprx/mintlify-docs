---
title: 'List Accounts'
api: 'GET /v2/accounts'
description: 'List all accounts associated with your API key'
---

Retrieve a paginated list of accounts linked to your API key. Use the returned `account_id` values in all subsequent V2 action requests.

<Note>
  This endpoint is **free** — it does not consume any credits.
</Note>

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

### Query Parameters

<ParamField query="count" type="integer" default="50">
  Maximum number of accounts to return per page (1-500).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of accounts to skip — use with `limit` to paginate (e.g. `offset=50&limit=50` for page 2).
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  Whether the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="Properties">
    <ResponseField name="items" type="array">
      <Expandable title="Account Object">
        <ResponseField name="account_id" type="string">
          Unique identifier for the account (use this in action requests)
        </ResponseField>

        <ResponseField name="platform" type="string">
          Platform type (e.g. "linkedin")
        </ResponseField>

        <ResponseField name="account_name" type="string">
          Display name of the account
        </ResponseField>

        <ResponseField name="is_active" type="boolean">
          Whether the account is currently active and usable
        </ResponseField>

        <ResponseField name="status" type="string">
          Account status, always in step with `is_active`:

          - `connected` — ready to use (`is_active: true`)
          - `checkpoint_required` — waiting on a 2FA code, see [Checkpoint](/api-reference/v2/accounts/checkpoint)
          - `disconnected` — the LinkedIn session expired; re-authenticate via [Connect Account](/api-reference/v2/accounts/login)
        </ResponseField>

        <ResponseField name="country" type="string">
          Country code associated with the account
        </ResponseField>

        <ResponseField name="created_at" type="string">
          ISO 8601 timestamp of when the account was created
        </ResponseField>

        <ResponseField name="updated_at" type="string">
          ISO 8601 timestamp of the last account update
        </ResponseField>

        <ResponseField name="sales_nav" type="object">
          State of the account's Sales Navigator seat.
          <Expandable title="sales_nav properties">
            <ResponseField name="connected" type="boolean">
              Whether the account currently has a usable Sales Navigator seat.
            </ResponseField>
            <ResponseField name="contract_id" type="string">
              Sales Navigator contract the seat belongs to. Present once a seat has been activated.
            </ResponseField>
            <ResponseField name="seat_id" type="string">
              The seat within that contract.
            </ResponseField>
            <ResponseField name="connected_at" type="string">
              ISO 8601 timestamp of the last seat activation or refresh. Only when `connected` is `true`.
            </ResponseField>
            <ResponseField name="reason" type="string">
              Why the seat is unavailable. Only when `connected` is `false` and a seat existed before.
            </ResponseField>
            <ResponseField name="disconnected_at" type="string">
              ISO 8601 timestamp of when the seat was lost. Only when the seat died on its own.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>

    </ResponseField>

    <ResponseField name="limit" type="integer">

    </ResponseField>

    <ResponseField name="offset" type="integer">
      The `offset` used for this request
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="object">
  <Expandable title="Properties">

    <ResponseField name="credits_consumed" type="integer">

    <ResponseField name="timestamp" type="string">

### Sales Navigator seat

Whether the account can run [lead searches](/api-reference/v2/profiles/search-people-nav), send InMails and read its [InMail balance](/api-reference/v2/messages/balance). The seat is derived from the LinkedIn session, so:

- account disconnects → seat goes with it; reconnecting restores it
- seat can die alone (expired licence, seat reassigned) → `is_active` stays `true`, `connected` turns `false` with a `reason`
- never had Sales Navigator → just `{ "connected": false }`

### Notes
- Use the `account_id` from the response in all V2 action requests
- Only accounts with `is_active: true` can be used for actions
- Results are sorted by `created_at` descending (newest first)
- Default page size is `50`; the maximum allowed `limit` is `500`. To page through all accounts, increment `offset` by `limit` until `offset + limit >= total`
