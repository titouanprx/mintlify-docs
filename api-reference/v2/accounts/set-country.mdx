---
title: 'Set Proxy Country'
api: 'POST /v2/accounts/{account_id}/country'
description: 'Change the country of the managed proxy of a connected LinkedIn account'
---

Moves an already-connected account to a LinkupAPI-managed proxy of another country. Every request of the account (actions, real-time webhooks, background checks) then exits from the new country.

<Note>
  This endpoint is **free** — it does not consume any credits.
</Note>

### Path Parameters

<ParamField path="account_id" type="string" required>
  A LinkedIn account of your API key
</ParamField>

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

### Body Parameters

<ParamField body="country" type="string" required>
  ISO 3166-1 alpha-2 code of the new proxy country, e.g. `TH`
</ParamField>

### Response

<ResponseField name="data" type="object">
  <Expandable title="Properties">
    <ResponseField name="country" type="string">
      Country now used by the account's proxy
    </ResponseField>
    <ResponseField name="previous_country" type="string">
      Country before the change
    </ResponseField>
    <ResponseField name="changed" type="boolean">
      `false` when the account was already on this country (nothing done)
    </ResponseField>
    <ResponseField name="session_verified" type="boolean">
      The LinkedIn session was accepted from an IP of the new country
    </ResponseField>
    <ResponseField name="webhooks_repinned" type="integer">
      Webhooks of the account moved to the new country
    </ResponseField>
  </Expandable>
</ResponseField>

### Notes
- The session is verified from the new country before applying — nothing changes on failure
- Device identity (device id, user agent) is preserved; only the exit IP changes
- Re-logging the account with another `country` on [Login](/api-reference/v2/accounts/login) also moves it
- Not available on accounts routed through a [custom proxy](/api-reference/v2/accounts/set-proxy): the country is defined by your proxy
