---
title: 'Set Custom Proxy'
api: 'POST /v2/accounts/{account_id}/proxy'
description: 'Route a LinkedIn account through your own proxy'
---

All requests of the account (actions, webhooks) go through your proxy. No fallback to LinkupAPI proxies.

<Note>
  This endpoint is **free** — it does not consume any credits.
</Note>

### Path Parameters

<ParamField path="account_id" type="string" required>
  A LinkedIn account of your API key
</ParamField>

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

### Body Parameters

<ParamField body="proxy" type="string | object" required>
  `http://user:pass@host:port`, `host:port:user:pass`, `host:port`, or `{ "host", "port", "username", "password" }`. HTTP(S) only.
</ParamField>

### Response

<ResponseField name="data" type="object">
  <Expandable title="Properties">
    <ResponseField name="proxy" type="object">
      `{ "mode": "custom", "host": "...", "port": 8080 }`
    </ResponseField>
    <ResponseField name="session_verified" type="boolean">
      The LinkedIn session works through the proxy
    </ResponseField>
  </Expandable>
</ResponseField>

### Notes
- The proxy is tested and the session verified before applying — nothing changes on failure
- Persistent across re-logins. Remove with [Remove Custom Proxy](/api-reference/v2/accounts/remove-proxy)
