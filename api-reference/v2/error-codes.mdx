All V2 API error responses follow a standardized format:

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable description of the error",
    "sub_code": "CANT_RESEND_YET"
  },
  "metadata": {
    "action": "the_action_attempted",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

`sub_code` is the machine-readable reason, present when we know it (always on `CHANNEL_ERROR`). Branch on `code` and `sub_code`, never on `message`: the text may change, the codes don't. See [Sub-codes](#sub-codes).

<Note>
  Errors caught before the request reaches the platform (API key, parameters, credits…) are free. Once it has reached the platform, a refusal (e.g. `CHANNEL_ERROR` / `CANT_RESEND_YET`) consumes **1 credit**, shown in `credits_consumed`.
</Note>

## Error Codes Reference

| Error Code | HTTP Status | Description |
|---|---|---|
| `INVALID_API_KEY` | 403 Forbidden | The provided API key is invalid, expired, or missing from the `x-api-key` header. |
| `INVALID_ACCOUNT` | 404 Not Found | The specified `account_id` does not exist or does not belong to your API key. |
| `ACCOUNT_INACTIVE` | 403 Forbidden | The account exists but is currently inactive or suspended. Reactivate the account before making requests. |
| `INVALID_ACTION` | 400 Bad Request | The requested `action` is not supported for this category endpoint, or not on this account (a Recruiter seat only runs Recruiter actions). Check the available actions in the documentation. |
| `INVALID_PARAMS` | 400 Bad Request | One or more required parameters are missing, or a parameter value is invalid — this also covers a target that no longer exists on LinkedIn, such as a deleted post. Check the `message` field for details. |
| `RATE_LIMITED` | 429 Too Many Requests | You are sending too many requests. Slow down and retry after a short delay. |
| `INSUFFICIENT_CREDITS` | 402 Payment Required | Your account does not have enough credits to perform this action. Top up your credits to continue. |
| `SEAT_LIMIT_REACHED` | 402 Payment Required | Per-account plan: no seat available for this account. Either you are connecting more accounts than your plan allows (auto-upgrade off), or the workspace has no active per-account plan. Manage it in Billing. |
| `CHANNEL_ERROR` | 422 Unprocessable Entity | The request was valid but the platform refused it — restricted profile, missing premium seat (e.g. no Sales Nav license), or an upstream failure. `sub_code` tells which: only `UPSTREAM_ERROR` and `*_UNAVAILABLE` are worth retrying. |
| `INTERNAL_ERROR` | 500 Internal Server Error | An unexpected server error occurred. If this persists, contact support. |

## Sub-codes

| Area | `sub_code` | Retry? |
|---|---|---|
| Temporary | `UPSTREAM_ERROR`, `WHATSAPP_UNAVAILABLE`, `SALES_NAV_SEAT_UNAVAILABLE`, `NO_PROXY_AVAILABLE`, `MONITOR_START_FAILED`, `MAILBOX_PROVIDER_ERROR` | Yes, after a short delay |
| Invitations | `CANT_RESEND_YET` (already connected, invitation pending, or withdrawn less than ~3 weeks ago), `ALREADY_CONNECTED`, `ALREADY_INVITED`, `CUSTOM_MESSAGE_TOO_LONG`, `INVITATION_REFUSED`, `INVITATION_NOT_CONFIRMED` (check with `check_invitation`), `INVITATION_NOT_PENDING` | No |
| Invitation limits (under `RATE_LIMITED`) | `QUOTA_EXCEEDED`, `FUSE_LIMIT_EXCEEDED` | Later |
| LinkedIn refusals | `PROFILE_RESTRICTED`, `ENTITY_NOT_FOUND`, `GEO_RESTRICTED`, `INMAIL_NOT_ALLOWED`, `JOB_POSTING_FAILED`, `LINKEDIN_REFUSED` | No |
| Sales Navigator | `NO_SALES_NAV_SEAT`, `SALES_NAV_SEAT_INVALID` (reconnect), `SALES_NAV_ACCESS_DENIED`, `SALES_NAV_BAD_REQUEST`, `SALES_NAV_NOT_FOUND`, `SALES_NAV_RATE_LIMITED`, `INMAIL_MONTHLY_FUSE_LIMIT`, `ACCOUNT_UNDER_REVIEW`, `MISSING_CONVERSATION_ID`, `SALES_NAV_ERROR` | No |
| Recruiter | `RECRUITER_SEAT_MISSING`, `RECRUITER_SEAT_EXPIRED` (reconnect), `NO_RECRUITER_LICENSE`, `RECRUITER_LOGIN_FAILED`, `RECRUITER_ERROR` | No |
| Login & checkpoint | `LOGIN_FAILED`, `ACCOUNT_RESTRICTED`, `INVALID_LOGIN_TOKEN`, `CHECKPOINT_VERIFICATION_FAILED`, `CHECKPOINT_SESSION_EXPIRED` (login again), `CHECKPOINT_RESEND_FAILED` | No |
| Accounts | `SESSION_REJECTED_THROUGH_PROXY` (proxy or country change refused, nothing changed) | No |
| Email | `MAILBOX_AUTHORIZATION_FAILED`, `MAILBOX_AUTH_FAILED`, `MAILBOX_AUTH_REVOKED`, `MAILBOX_PERMISSIONS_MISSING`, `MAILBOX_CONNECTION_FAILED`, `NO_GMAIL_MAILBOX`, `MICROSOFT_SENDING_UNAVAILABLE`, `IMAP_AUTH_FAILED`, `IMAP_CONNECTION_FAILED` | No |
| WhatsApp | `WHATSAPP_LINK_EXPIRED`, `WHATSAPP_LINK_REFUSED`, `NOT_ON_WHATSAPP`, `SEND_FAILED`, `NOT_CONNECTED`, `CHAT_NOT_FOUND` | No |
| Other | `COMPANY_NOT_FOUND` (enrich), `CONNECT_LINK_UNAVAILABLE`, `CONNECTION_FAILED` (hosted connection links) | No |

New sub-codes may be added; treat an unknown one like its `code`.

## Error Code Details

### INVALID_API_KEY (403)

Returned when the `x-api-key` header is missing or contains an invalid key.

```json
{
  "success": false,
  "error": {
    "code": "INVALID_API_KEY",
    "message": "The provided API key is invalid or missing"
  },
  "metadata": {
    "action": "get_profile",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Verify your API key in the [dashboard](https://app.linkupapi.com) and ensure it is included in the `x-api-key` header.

### INVALID_ACCOUNT (404)

Returned when the `account_id` in the request body does not match any account under your API key.

```json
{
  "success": false,
  "error": {
    "code": "INVALID_ACCOUNT",
    "message": "The specified account_id does not exist"
  },
  "metadata": {
    "action": "get_profile",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Call `GET /v2/accounts` to list your available accounts and use a valid `account_id`.

### ACCOUNT_INACTIVE (403)

Returned when the account exists but is not currently active.

```json
{
  "success": false,
  "error": {
    "code": "ACCOUNT_INACTIVE",
    "message": "This account is currently inactive"
  },
  "metadata": {
    "action": "get_profile",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Check the account status with `GET /v2/accounts/{account_id}`. To reactivate the account, log in again via `POST /v2/login` with the same credentials.

### INVALID_ACTION (400)

Returned when the `action` field contains an unsupported action for the category endpoint.

```json
{
  "success": false,
  "error": {
    "code": "INVALID_ACTION",
    "message": "Unknown action 'foo_bar' for category 'profiles'"
  },
  "metadata": {
    "action": "foo_bar",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Refer to the documentation for the category you are calling to see available actions.

It is also returned when a non-Recruiter action is called with a **Recruiter seat's** `account_id`. The seat holds the Recruiter session only, so it can't run classic or Sales Nav actions (profile, connections, feed, invitations, search…). Nothing is sent to LinkedIn and no credit is charged. Call the action with the LinkedIn account named in the message instead (the seat's `parent_account_id`):

```json
{
  "success": false,
  "error": {
    "code": "INVALID_ACTION",
    "message": "This account_id is a LinkedIn Recruiter seat: it only runs Recruiter actions, and network/list_connections is not one. Call it with its LinkedIn account (account_id 69c127c37cae0494dd827286)."
  },
  "metadata": {
    "action": "list_connections",
    "credits_consumed": 0,
    "timestamp": "2026-10-07T12:00:00Z"
  }
}
```

### INVALID_PARAMS (400)

Returned when required parameters are missing or parameter values are invalid.

```json
{
  "success": false,
  "error": {
    "code": "INVALID_PARAMS",
    "message": "Missing required parameter: profile_url"
  },
  "metadata": {
    "action": "get_profile",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Check the `message` field for the specific parameter issue and refer to the action's documentation.

### RATE_LIMITED (429)

Returned when you exceed the API rate limit.

```json
{
  "success": false,
  "error": {
    "code": "RATE_LIMITED",
    "message": "Rate limit exceeded. Please try again later"
  },
  "metadata": {
    "action": "get_profile",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Implement exponential backoff in your requests. Wait a few seconds before retrying. LinkedIn-side limits carry a `sub_code` (`QUOTA_EXCEEDED`, `FUSE_LIMIT_EXCEEDED`, `SALES_NAV_RATE_LIMITED`, `INMAIL_MONTHLY_FUSE_LIMIT`): those reset on LinkedIn's schedule, not in seconds.

### INSUFFICIENT_CREDITS (402)

Returned when your account does not have enough credits for the requested action.

```json
{
  "success": false,
  "error": {
    "code": "INSUFFICIENT_CREDITS",
    "message": "Insufficient credits. This action requires 3 credits, but you have 1 remaining"
  },
  "metadata": {
    "action": "search_profiles",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Top up your credits at [app.linkupapi.com](https://app.linkupapi.com).

### SEAT_LIMIT_REACHED (402)

Returned on the per-account plan when no seat is available for the account you are connecting. Two causes, told apart by the `message`: you already have as many connected accounts as your plan allows and auto-upgrade is off, or the workspace has no active per-account plan at all (checkout never completed, trial ended without a card).

```json
{
  "success": false,
  "error": {
    "code": "SEAT_LIMIT_REACHED",
    "message": "No account seat available: this workspace has no active per-account plan. Subscribe at https://app.linkupapi.com/billing"
  },
  "metadata": {
    "action": "login",
    "credits_consumed": 0,
    "timestamp": "2026-10-12T12:00:00Z"
  }
}
```

**How to fix:** Open [Billing](https://app.linkupapi.com/billing) to subscribe to the per-account plan, add seats, or turn auto-upgrade on. `INSUFFICIENT_CREDITS` is only returned to credit customers whose balance is at zero, and for email enrichment, which is billed in credits on every plan.

### CHANNEL_ERROR (422)

Returned when the request was valid but the platform refused it. `sub_code` gives the reason; see [Sub-codes](#sub-codes).

```json
{
  "success": false,
  "error": {
    "code": "CHANNEL_ERROR",
    "message": "No Sales Nav license found for this account",
    "sub_code": "NO_SALES_NAV_SEAT"
  },
  "metadata": {
    "action": "search_people_nav",
    "credits_consumed": 1,
    "timestamp": "2026-10-15T12:00:00Z"
  }
}
```

**How to fix:** Branch on `sub_code`. Retry only the temporary ones (`UPSTREAM_ERROR`, `*_UNAVAILABLE`); for the others, change the request or the account (seat, licence, reconnection).

### INTERNAL_ERROR (500)

Returned when an unexpected error occurs on the server.

```json
{
  "success": false,
  "error": {
    "code": "INTERNAL_ERROR",
    "message": "An unexpected error occurred while processing your request"
  },
  "metadata": {
    "action": "get_profile",
    "credits_consumed": 0,
    "timestamp": "2026-03-24T12:00:00Z"
  }
}
```

**How to fix:** Retry after a few seconds. If the error persists, contact [support@linkupapi.com](mailto:support@linkupapi.com).
