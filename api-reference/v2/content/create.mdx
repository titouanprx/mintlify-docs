---
title: 'Create Post'
api: 'POST /v2/content'
description: 'Create a new post with text, images, video, a document, or carousel content.'
---

## Overview

Create a post from the authenticated account. Supports plain text posts, single image, video or document attachments, and multi-image carousels.

<Note>This endpoint consumes **1 credit** per request.</Note>

## Request

<ParamField header="x-api-key" type="string" required>
  Your API key for authentication.
</ParamField>

<ParamField body="account_id" type="string" required>
  The unique identifier of the account to use.
</ParamField>

<ParamField body="action" type="string" required>
  Must be `"create"`.
</ParamField>

<ParamField body="params" type="object">
  <Expandable title="params properties">
    <ParamField body="message" type="string">
      The text content of the post. Supports hashtags (`#tag`), line breaks and people mentions.
      To mention someone, use `mention_user(public_id, display_text)` where `public_id` is the slug of their profile URL (`linkedin.com/in/<public_id>`) and `display_text` is the clickable text shown in the post — e.g. `"Great talk mention_user(williamhgates, Bill Gates)!"`. To mention a company page, use `mention_company(slug, display_text)` where `slug` is from `linkedin.com/company/<slug>` — e.g. `"Proud to partner with mention_company(microsoft, Microsoft)"`.
    </ParamField>
    <ParamField body="file" type="string | object">
      A single file to attach — an image (`.jpg`, `.png`, `.gif`, `.webp`), a video (`.mp4`, `.mov`, `.webm`…) or a document (`.pdf`, `.doc`, `.docx`, `.ppt`, `.pptx`), which LinkedIn publishes as a page carousel. Can be a URL string or an object with `filename` and `data` properties.
      <Expandable title="file object properties">
        <ParamField body="filename" type="string">
          The name of the file including extension (e.g. `"photo.jpg"`).
        </ParamField>
        <ParamField body="data" type="string">
          Base64-encoded file data.
        </ParamField>
      </Expandable>
    </ParamField>
    <ParamField body="thumbnail" type="string | object">
      Custom cover image for a video post. Only valid when `file` is a single video (`.mp4`, `.mov`, `.webm`…). Same format as `file`: a URL string or an object with `filename` and `data` (base64). Without it, LinkedIn picks a frame of the video.
    </ParamField>
    <ParamField body="document_title" type="string">
      Title displayed under a document post, and used by LinkedIn to build the post URL. Only valid when `file` is a document. Defaults to the file name without its extension.
    </ParamField>
    <ParamField body="files" type="array">
      An array of files for carousel posts. Each element can be a URL string or an object with `filename`, `data`, and optional `altText` properties.
      <Expandable title="file object properties">
        <ParamField body="filename" type="string">
          The name of the file including extension.
        </ParamField>
        <ParamField body="data" type="string">
          Base64-encoded file data.
        </ParamField>
        <ParamField body="altText" type="string">
          Alternative text for the image (accessibility).
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>


## Response

<ResponseField name="success" type="boolean">
  Indicates whether the request was successful.
</ResponseField>

<ResponseField name="data" type="object">
  The created post data.
  <Expandable title="data properties">
    <ResponseField name="post_url" type="string">
      The URL of the newly created post.
    </ResponseField>
    <ResponseField name="post_urn" type="string">
      Unique identifier of the post. Treat it as an opaque string and pass it back exactly as returned.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="object">
  <Expandable title="metadata properties">
    <ResponseField name="action" type="string">
      The action that was performed (`"create"`).
    </ResponseField>
    <ResponseField name="account_id" type="string">
      The account ID used for the request.
    </ResponseField>
    <ResponseField name="credits_consumed" type="integer">
      Number of credits consumed (1).
    </ResponseField>
    <ResponseField name="timestamp" type="string">
      ISO 8601 timestamp of the response.
    </ResponseField>
  </Expandable>
</ResponseField>
