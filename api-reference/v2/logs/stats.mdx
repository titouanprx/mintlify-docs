---
title: 'Usage Stats'
api: 'GET /v2/logs/stats'
description: 'Aggregated request counts and credits, per LinkedIn account and per action'
---

Totals over your **whole** history (not capped by pagination): number of calls, successes, errors and credits, broken down by LinkedIn account and by action. Served from our store: **no LinkedIn traffic** and **no credits consumed**.

Pass `account_id` to get the per-action detail of a single account.

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

### Query Parameters

<ParamField query="account_id" type="string">
  Scope every figure to this LinkedIn account. `by_account` then holds one row and `by_action` is the breakdown of that account.
</ParamField>

<ParamField query="date_from" type="string">
  ISO date (`YYYY-MM-DD`) or datetime. Only calls at or after this moment.
</ParamField>

<ParamField query="date_to" type="string">
  ISO date or datetime. A date-only value is **inclusive** of that whole day.
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  Whether the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="Properties">
    <ResponseField name="total_calls" type="integer">
      Number of calls in the range
    </ResponseField>
    <ResponseField name="total_credits" type="number">
      Credits consumed in the range
    </ResponseField>
    <ResponseField name="by_account" type="array">
      One row per LinkedIn account, most calls first. `account_id` is `null` for calls without an account (email enrichment, account management)
      <Expandable title="Row">
        <ResponseField name="account_id" type="string">LinkedIn account</ResponseField>
        <ResponseField name="total" type="integer">Calls</ResponseField>
        <ResponseField name="success" type="integer">Successful calls</ResponseField>
        <ResponseField name="error" type="integer">Failed calls</ResponseField>
        <ResponseField name="credits" type="number">Credits consumed</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="by_action" type="array">
      One row per action, most calls first. Same fields, keyed by `action`
    </ResponseField>
  </Expandable>
</ResponseField>

### Notes
- This endpoint does **not** consume any credits
- `credits` can exceed `total` for actions billed more than one credit per call (Sales Navigator search, bulk actions)
- Failed calls are logged with `credits_consumed: 0`
