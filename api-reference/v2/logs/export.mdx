---
title: 'Export Logs'
api: 'GET /v2/logs/export'
description: 'Download your API call history as a CSV file'
---

Same rows and filters as [List API Logs](/api-reference/v2/logs/list-logs), returned as a single CSV file with no pagination. **No credits consumed.**

### Header Parameters

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

### Query Parameters

<ParamField query="action" type="string">
  Only calls of this action.
</ParamField>

<ParamField query="account_id" type="string">
  Only calls made with this LinkedIn account.
</ParamField>

<ParamField query="status" type="string">
  `success` or `error`.
</ParamField>

<ParamField query="date_from" type="string">
  ISO date (`YYYY-MM-DD`) or datetime. Only calls at or after this moment.
</ParamField>

<ParamField query="date_to" type="string">
  ISO date or datetime. A date-only value is **inclusive** of that whole day.
</ParamField>

### Response

`text/csv`, served as an attachment (`linkup_api_logs.csv`), newest row first. Columns:

| Column | Content |
|---|---|
| `date` | ISO 8601 timestamp (UTC) |
| `action` | The action called |
| `status` | `success` or `error` |
| `credits_consumed` | Credits charged |
| `account_id` | LinkedIn account, empty when not applicable |
| `error_message` | Empty on success |

### Notes
- Always narrow with `date_from` / `date_to` on large histories; the export is capped at 100,000 rows
